# Task Tracer CLI

Um gerenciador de tarefas via terminal, que tem persistencia de dados em um arquivo JSON com data e horario de criação e de atualização.

## Aprendizados

Gerenciar arquivos Json com libs nativas
Construir um app com comandos via terminal

## Principais funções via terminal

- Adicionar Tarefa
- Ler Tarefa
- Atualizar Tarefa
- Deletar Tarefa

- Marcar Tarefas como **Pendente**
- Marcar Tarefas como **Em andamento**
- Marcar Tarefas como **Concluído**

- Listar todas as tarefas
- Listar Tarefas por status (**Pendente**, **Em andamento**, **Concluído**)

## Como utilizar esta aplicação

```bash
git clone https://github.com/lbeneylton/TASKS_CLI
cd TASKS_CLI
```
